GIFs das respostas em LIBRAS
============================

Cada resposta foi gravada pela Juliana e pelo João; o app alterna entre os
dois, para cada um aparecer o mesmo número de vezes. Para gerar um GIF a
partir de um vídeo (corte só uma repetição do sinal):

    python backend/video_para_gif.py VIDEO.mp4 assets/respostas/NOME.gif --largura 300 --fps 10 --inicio 8.3 --duracao 3.4

Arquivos que o app usa (definidos em lib/frases.dart):

  Olá, tudo bem?
    estou_bem_juliana.gif / estou_bem_joao.gif            "Estou bem"
    nao_estou_bem_juliana.gif / nao_estou_bem_joao.gif    "Não estou bem"

  Qual seu nome?
    meu_nome_juliana.gif                                  "Meu nome é..." (falta o do João)
    nao_entendi_juliana.gif / nao_entendi_joao.gif        "Não entendi"

  Onde é o banheiro?
    direita_juliana.gif / direita_joao.gif                "À direita"
    esquerda_juliana.gif / esquerda_joao.gif              "À esquerda"
    nao_sei_juliana.gif / nao_sei_joao.gif                "Não sei" (usado em várias frases)

  Quanto custa?
    gratis_juliana.gif / gratis_joao.gif                  "É de graça"

  Que horas são?
    uma_hora_juliana.gif / uma_hora_joao.gif              "É 1 hora"
    duas_horas_juliana.gif / duas_horas_joao.gif          "São 2 horas"
    tres_horas_juliana.gif / tres_horas_joao.gif          "São 3 horas"

Enquanto um GIF não existir, o app mostra um aviso no lugar dele.
